- Search by filename, folder, tags and extracted text
- Open/preview

## Important limitation
This static GitHub Pages version stores files only inside the browser on the current device.
Full cross-device synchronization, account access and AI reading of all PDFs/charts require the planned cloud backend and AI indexing service.
