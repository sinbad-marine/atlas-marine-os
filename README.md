# Atlas Marine OS v6.1 — Corrected Cloud Control Center

This corrected version makes the cloud modules visible from the top hero area.

## Added
- Open Cloud Control Center hero button
- Cloud Documents hero button
- Supabase configuration and login
- Workspace selection
- Member role update UI
- Cloud upload
- Open, download, share, rename and delete
- AI indexing request and job monitor
- Security configuration check
- Local Document Center shortcut

## Important
Role changes, deletes and uploads are still enforced by Supabase RLS.
Live AI requires the Edge Functions `captain-sinbad` and `index-document`.
